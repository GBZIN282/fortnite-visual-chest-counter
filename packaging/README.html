Fortnite Visual Chest Counter

Visual chest detection for OBS, capture cards & video files · v0.1.0 public beta · Windows 10 / 11 · no Python or programming needed

What this is

A small helper for streamers. It watches your gameplay picture (through OBS) and keeps a running count of the chests you open in Fortnite. It writes the numbers into text files that you show on stream with a normal OBS text source. You choose the font, size and colours in OBS. It does not touch Fortnite, the game files or your account: it only looks at the video picture, like a viewer would.

CERTAIN OPENED CHESTS

Chests the counter is strongly confident about. A safe, conservative number.

APPROX. OPENED CHESTS

The estimated TOTAL of opened chests, including the certain ones. It also adds chests where the evidence was a bit weaker.
Important - the two numbers are NOT added together.
CERTAIN: 12 and APPROX: 47 means “about 47 chests in total, and 12 of those I am very sure about”. It does not mean 59. APPROX is always the same as or higher than CERTAIN.

This is a public beta. APPROX is an estimate, not a perfect count. In our recorded test streams it matched the real number closely, but computer vision is never 100%. See Known limitations.

What you need

  • Windows 10 or 11 on the PC that runs OBS (your streaming PC if you have two).
  • OBS Studio 28 or newer (it has the Virtual Camera built in).
  • Fortnite shown in a 16:9 picture (1920×1080 is ideal; 1280×720 or higher works) with the normal HUD visible, in English or Brazilian Portuguese.
  • About half of one CPU core. No graphics card needed.
  • Nothing else to install. The video helper (FFmpeg) is already inside the folder.

The 30-second version

  1. Unzip the folder anywhere you can write files (Desktop or Documents is fine).
  2. In OBS: make a scene called ChestDetectorFeed with only your game in it, and start the Virtual Camera from that scene.
  3. Double-click Start Chest Counter.bat and play.
  4. In OBS, add two Text sources that read obs_output\certain_chests.txt and obs_output\approximate_chests.txt.

Details for each step are below.

Single-PC setup (game and OBS on the same PC)

1. Unzip

Right-click the zip → Extract All. Do not run it from inside the zip, and don’t put it in Program Files. The folder contains:

Fortnite Visual Chest Counter.exe (the program; you normally don't open this directly)
Start Chest Counter.bat        <- the one you double-click
Reset Counter.bat              set both counts to 0
Show Counter.bat               look at the current counts
Count Video File.bat           drag a recorded video onto this file to count it
Diagnostics.bat                for support, if something does not work
README.html                    this guide
config.example.toml            optional settings (see "Settings")
obs_output\                    the text files OBS reads
state\  logs\                  your counter and logs (kept when you update)
runtime\                       program files - don't touch

2. Make a clean feed for the counter in OBS

The counter must see only the game picture (no webcam, alerts or overlays covering the screen). The easiest way is a separate scene that you never show on stream.

  1. Open OBS. In the Scenes box click + and name the scene exactly ChestDetectorFeed.
  2. In the Sources box click + → Game Capture → OK. Set Mode to “Capture specific window” and choose Fortnite (start Fortnite first so it appears in the list). If Game Capture shows a black picture, use Display Capture instead.
  3. Make Fortnite fill the whole scene: select the source and press Ctrl+F (“Fit to screen”).
  4. Do not add a webcam, alerts, chat or the chest-counter text to this scene.

3. Start the Virtual Camera from that scene

  1. In OBS, find the Controls box (bottom-right). Click the small gear next to Start Virtual Camera.
  2. Set Output Type to Scene and Output Selection to ChestDetectorFeed. Close the window.
  3. Click Start Virtual Camera. It now shows as running.

Your normal stream scene is unaffected: viewers still see whatever scene you choose. The counter reads only ChestDetectorFeed.

4. Start the counter

Double-click Start Chest Counter.bat. A black window opens and shows lines like:

Connected: video 1920x1080 @ 30.0 fps -> analysed at 15 frames per second
Counting has started. Counts are kept when you stop and restart.
LIVE  15.0 detector fps | source 30.0 fps | CERTAIN 0 | APPROX 0 | dropped 0 | 6 ms/frame

Leave that window open while you play (minimise it if you like). Each time a chest is counted a line is printed. To stop: press Q in the window, or just close it. Your numbers are saved after every chest.

If you see “OBS Virtual Camera was not found”, follow the three steps it prints (open OBS, Start Virtual Camera, run again).

5. Show the numbers on stream

See Show it on stream below.

Two-PC setup (gaming PC + streaming PC with a capture card)

Gaming PC / console ↓ HDMI Capture card ↓ Streaming PC → OBS → scene "ChestDetectorFeed" → Virtual Camera → Fortnite Visual Chest Counter
  • Install and run the counter on the streaming PC (the one running OBS). Nothing needs to run or be installed on the gaming PC or console.
  • In OBS on the streaming PC, create the ChestDetectorFeed scene and add your capture card as a Video Capture Device source. Make it fill the scene (Ctrl+F). Nothing else goes in this scene.
  • Set the Virtual Camera to Scene → ChestDetectorFeed and click Start Virtual Camera (exact clicks in step 3 above).
  • Double-click Start Chest Counter.bat — the same launcher as everyone else.
Advanced: reading the capture card directly (no Virtual Camera). Possible, but many capture cards can only be opened by one program at a time, so it does not work while OBS is using the card. To try: make a copy of config.example.toml named config.toml, set source = "device" and device = "exact device name" under [live] (Diagnostics.bat lists the names), and start the counter. If it says the device cannot be opened, switch back to the Virtual Camera method.

Show it on stream (OBS text sources)

The counter only writes the text. You style it in OBS however you like.

  1. Open the scene your viewers see (not ChestDetectorFeed).
  2. In Sources click + → Text (GDI+) → name it “Certain chests” → OK.
  3. Tick Read from file, click Browse and choose obs_output\certain_chests.txt (inside the counter folder).
  4. Choose a font, size and colour. Click OK and place it on screen.
  5. Repeat for obs_output\approximate_chests.txt (name it “Approx chests”).
File (in obs_output)Shows
certain_chests.txtCERTAIN OPENED CHESTS: 12
approximate_chests.txtAPPROX. OPENED CHESTS: 47
chest_status.txtOne compact line: 12 certain • ~47 estimated — use this instead if you only want a single text source.
last_chest.txtThe most recent chest, e.g. CHEST +1 • HIGH.

Numbers over 999 get a thousands separator (1,232). Only the counter writes these files; don’t edit them by hand. The words (“CERTAIN OPENED CHESTS”…) can be changed in config.toml.

Put these text sources only in the scene your viewers see, never in ChestDetectorFeed.

Counting a recorded video

The counter can also analyse a prerecorded gameplay video (.mp4, .mkv, .mov…). Drag the video file and drop it onto Count Video File.bat. It runs faster than real time, prints each counted chest and a progress line every minute of video, and finishes with the CERTAIN and APPROX numbers (APPROX includes CERTAIN). This never changes your live counter; result text files go to video_output\. The video should be clean 16:9 gameplay with the normal HUD, in English or Brazilian Portuguese.

Reset the counter (e.g. at the start of a stream)

Double-click Reset Counter.bat. It prints

Counter reset:
  CERTAIN: 0
  APPROX: 0

and waits for a key. It works even while the counter window is open — the open window picks up the new zeros within a second. Show Counter.bat displays the current numbers without changing anything. Closing and reopening the counter does not reset it; your totals continue.

Settings (optional)

Most people never need to change anything. The defaults work. If you want to change labels, languages or similar, copy config.example.toml to config.toml, edit it with Notepad (every option is explained inside), save, and restart the counter. A mistake in the file only produces a warning and the default is used for that option.

OptionWhat it does
languagesFortnite language(s). ["en"] or ["pt"] removes the other language’s lookalikes.
certain_min_tier"CERTAIN" makes the CERTAIN number stricter (lower).
count_*_as_approxSwitch the weaker kinds of evidence on/off for APPROX.
certain_label, approximate_labelThe words in front of the numbers.
use_thousands_separator1,232 or 1232.
process_fpsFrames analysed per second (default 15).
loggingTurn session logs on/off.

Updating to a new version

Your counter, settings and logs are stored next to the program files, never inside them:

KeepWhat it is
state\Your saved counts.
config.tomlYour settings (if you made one).
logs\Session logs (optional to keep).
obs_output\The text files OBS reads (they are re-created automatically).

Easiest update: close the counter, then extract the new zip into the same folder and choose “Replace the files”. The zip never contains your counts or config.toml, so they are untouched. Afterwards double-click Show Counter.bat once so the OBS text files show your real numbers again (the zip contains blank placeholders). If you extract to a new folder instead, copy state\ and config.toml across, and re-point the two OBS text sources to the new obs_output folder.

Troubleshooting

ProblemFix
“OBS Virtual Camera was not found”Open OBS Studio (version 28+) and click Start Virtual Camera, then start the counter again.
“exists but is not sending video”Click Start Virtual Camera again; check the ChestDetectorFeed scene actually shows the game (not black).
Windows says “Windows protected your PC”The program is not code-signed (it’s a free hobby tool). Click More info → Run anyway. If your antivirus quarantines the .exe, add the folder as an exception.
The number never changesIs the picture 16:9 and the HUD visible? Does the chest popup (“CHEST” / “BAÚ”) appear in ChestDetectorFeed? Webcam/alerts covering the HUD hide it. Run Diagnostics.bat.
“already running in another window”Only one counter can run at a time. Use the window that is already open.
It missed a chest / counted something wrongHelp improve it: in config.toml set save_snapshots = true under [logging]. Each pop-up the counter considered is then saved as a small picture in logs\snapshots\ (only the pop-up area, nothing else). Send the pictures of the misses with the session log from logs\.
Text in OBS is blank or not updatingIn the Text source tick Read from file and check it points to the obs_output folder of the counter you are running.
Wrong numbers / want to fix by handRun the counter folder’s Fortnite Visual Chest Counter.exe adjust --certain 1 --approx 1 from a command window (use negative numbers to subtract), or Reset.
Anything elseDouble-click Diagnostics.bat, then copy its output (also saved to logs\diagnostics.txt) into your message. If the program ever crashes it saves logs\crash_*.txt — send that too.

Known limitations (please read)

  • APPROX is an estimate. It can be a little high or low. CERTAIN is the conservative number; APPROX is the best guess of the total.
  • Language: chest detection uses the word in the pop-up. Supported: English (CHEST) and Brazilian Portuguese (BAÚ). Other languages are not supported yet.
  • HUD layout: it expects the normal HUD position and size at a 16:9 picture. Heavily moved/scaled HUD, hidden HUD or a 4:3 / vertical picture will not work well.
  • Clean gameplay feed recommended: overlays, webcam or alerts on top of the HUD can hide the clues.
  • Audio is not used. Only the picture is analysed.
  • Tested on a limited number of recordings (PC English and PS5 Portuguese). Other platforms or settings may behave differently — that’s why this is a beta.

Privacy and safety

The counter makes no internet connection and sends nothing anywhere. It only reads video frames from the OBS Virtual Camera (or the capture device you pick) and writes text files and logs in its own folder. It does not inject into, read memory from or modify Fortnite.
